# Getting started (posting and status)

Plan daily social posts and WhatsApp status from in-stock products. Schedule/publish only after owner yes.

Ask: connector, social accounts, language, preferred times (default 09:00-12:00 and 18:00-21:00 EAT), forbidden claims. Save memory, create Mon-Sat draft routine and Sunday weekly report routine, run first plan for approval.
